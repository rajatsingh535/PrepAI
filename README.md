# PrepAI 🚀

**PrepAI** is an AI-powered interview preparation platform built with the MERN stack and Groq for ultra-fast AI inference. It helps users practice technical interviews, solve DSA problems, and receive real-time feedback.

---

## 🌐 Live Demo

Try the live application: [PrepAI Beta](https://prep-ai-beta-lovat.vercel.app)

---

## ✨ Key Features

- **AI Interview Simulation**: Interactive mock interview sessions powered by Groq LLMs.
- **DSA Coding Environment**: In-browser compiler with custom test case validation.
- **LeetCode Integration**: Integrated with Hosted LeetCode APIs for real-world DSA problem sets.
- **Robust Parsing**: Custom AI response parsing (`parseAIJSON`) ensuring reliable evaluation outputs.

---

## 🛠️ Tech Stack

- **Frontend**: React.js, JavaScript, HTML5/CSS3
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **AI Integration**: Groq API
- **Deployment**: Vercel
